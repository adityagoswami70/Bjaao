# Bjaao

A small music-themed landing page for party and mood-based playlists.

## Run locally

1. Open the project folder.
2. Double-click `music.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/music.html
```

## Included files

- `music.html` – main webpage
- `WhatsApp Audio 2026-10-27 at 1.29.39 PM.mp4` – Diwali audio used by the page

## Notes

The Diwali Party button is wired to play the local WhatsApp audio file from the same folder.
